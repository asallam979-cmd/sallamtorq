# SA.TORQ mobile homepage update

## Included changes

- Mobile-only professional homepage composition: cinematic Egypt × Italy motorcycle background, compact SA.TORQ header, and lower hero copy.
- Removed the crowded desktop navigation row from the mobile homepage only.
- The three-line menu button opens a vertical list on the left with the site's original section names and links, including its catalogs and account page.
- Inner content/catalog pages now use the same mobile hamburger-and-drawer pattern. The drawer retains the page's original navigation links and provides direct access to the site's existing sections and catalog pages.
- Mobile navigation styling is restricted to screens at or below 600px; desktop navigation and page content retain their original rules.
- Embedded the mobile hero photo in the homepage HTML so the background still appears when the folder is opened locally.
- Loaded the mobile stylesheet and menu script from the document head so direct local opening initializes the mobile layout and navigation.
- Kept desktop and laptop rules outside the new mobile-only stylesheet.
